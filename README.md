# BMG Social Media – Medien für geplante Posts

Öffentliches Ablage-Repo der Be My Guest Lodge (Table View, Kapstadt).
Der Publisher-Agent legt hier Reels und Bilder ab, die **zur Veröffentlichung bestimmt** sind. Metricool lädt sie über den öffentlichen Link (`raw.githubusercontent.com`) und plant den Post als **Entwurf**. Jan gibt jeden Post einmal frei, erst dann wird er veröffentlicht.

## Regeln
- Nur Material, das ohnehin öffentlich gepostet wird. Keine Gästefotos ohne Erlaubnis, keine Rechnungen, Daten oder Zugänge.
- Ordner: `reels/` (MP4, 9:16, H.264) · `images/` (JPG/PNG)
- Dateiname: `JJJJ-MM-<thema>-<format>.mp4`, z. B. `2026-11-sunset-season-reel.mp4`
- Dateien unter 50 MB halten.
